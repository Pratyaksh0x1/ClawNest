DOCUMENTATION & QUICKSTART

Everything you need to configure your vessel, setup API credentials, and navigate ClawNest like a veteran pirate captain.

1

Run the 1-Line Install Command

Run this in PowerShell (Windows) or Terminal (macOS/Linux). It automatically prepares Bun and sets up the clawnest global command:

# Windows PowerShell:
irm https://raw.githubusercontent.com/Pratyaksh0x1/ClawNest/main/website/public/install.ps1 | iex

# macOS / Linux:
curl -fsSL https://raw.githubusercontent.com/Pratyaksh0x1/ClawNest/main/website/public/install.sh | bash
2

Configure Your API Keys

Navigate to your ClawNest directory (or current workspace) and copy the example environment file:

cp .env.example .env

Add your free OpenRouter API key so the AI models can generate plans and write code for you.

3

Wake Up Your Crew

Open any terminal in your project workspace and run:

clawnest wakeup

Select CLI to start chatting with Agent, Plan, or Ask mode!

Environment Variables Reference

ClawNest reads configuration from a .env file in the project root or user home directory.

# Required for AI Agent, Plan, and Ask modes:
OPENROUTER_API_KEY="sk-or-v1-your-key-here"

# Optional: specify your preferred OpenRouter model (defaults to openrouter/free):
OPENROUTER_DEFAULT_MODEL="meta-llama/llama-3.3-70b-instruct:free"

# Optional: Telegram bot token from @BotFather (for Telegram mode):
TELEGRAM_BOT_TOKEN="123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"

# Optional: Firecrawl key for live web search and scraping in Plan mode:
FIRECRAWL_API_KEY="fc-your-key-here"
💡 Tip: You can get a free OpenRouter key from openrouter.ai to access dozens of free models!

Frequently Asked Questions

Q: Windows PowerShell says "running scripts is disabled"?

Run this command in PowerShell to temporarily allow install scripts for your current session:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Q: Command 'clawnest' is not recognized after install?

Restart your terminal window so the updated user PATH takes effect, or ensure $HOME\.local\bin (or ~/.bun/bin) is in your environment PATH.

Q: Is Git required?

Yes! The installer uses Git to fetch the latest ClawNest logbook and tools from GitHub. Download Git from git-scm.com if you don't have it installed.
